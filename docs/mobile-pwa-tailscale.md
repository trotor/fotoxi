# Fotoxi on your phone — install as a PWA over Tailscale

Fotoxi is now an installable **PWA** (Progressive Web App). Combined with
**Tailscale Serve** (private HTTPS), you can install it on your iPhone home
screen and browse your whole library from anywhere your home machine is online —
no public exposure, no separate login.

Why HTTPS: a PWA's service worker (what makes it installable and app-like) only
works over HTTPS or `localhost`. Tailscale Serve gives your machine a trusted
HTTPS URL on your private tailnet, which satisfies this.

## One-time setup

### 1. Tailscale on the home machine (macOS)

1. Install Tailscale and sign in: <https://tailscale.com/download>
2. In the Tailscale admin console, enable **MagicDNS** and **HTTPS
   Certificates** (DNS settings). This gives your machine a name like
   `mymac.tailnet-name.ts.net`.

### 2. Run Fotoxi (bind to localhost — Tailscale proxies it)

```bash
source .venv/bin/activate
python fotoxi.py serve --host 127.0.0.1     # port 8001 by default
```

### 3. Expose it over HTTPS with Tailscale Serve

```bash
tailscale serve --bg 8001
tailscale serve status        # prints your HTTPS URL
```

You'll get a URL like `https://mymac.tailnet-name.ts.net/`. That URL serves
Fotoxi over trusted HTTPS, reachable only from devices on your tailnet.

To stop serving later: `tailscale serve --https=443 off`.

### 4. Tailscale on the iPhone + install the app

1. Install the **Tailscale** app from the App Store and sign in with the **same
   account**; make sure it's connected (toggle on).
2. Open **Safari** and go to your `https://…​.ts.net/` URL.
3. Tap **Share** → **Add to Home Screen** → **Add**.

Fotoxi now has its own icon and opens full-screen (standalone), like a native
app.

## What works, and what needs the home machine online

- **App shell** (the UI) is cached, so the app opens instantly and even loads
  offline — but it needs the network for data.
- **Thumbnails, search, metadata, full images** are fetched live from the home
  machine. When the Mac is asleep/offline, you'll see the app shell but data
  won't load. (There is intentionally no offline photo cache.)
- **Full-resolution originals** are served from the home machine's disk.

## Notes

- No app-level authentication — the private tailnet is the security boundary.
  Don't expose the port publicly or via Tailscale Funnel unless you add auth.
- Related roadmap items: #25 (Tailscale), #21 (central server), #26 (full-res
  proxy from origin host), #17 (shared DB/thumbnails). A 24/7 "cloud read-only
  DB + thumbnail replica" (so mobile works even when home is off) is possible
  future work — see those issues.
- App icons live in `frontend/public/icons/` and are generated by
  `frontend/scripts/generate_icons.py`; swap them for a custom icon anytime and
  rebuild.
